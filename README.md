# Aortico Landing Page

Standalone static landing page for Aortico.

## Local preview

Open `index.html` directly, or serve this directory with any static web server.

## Cloudflare Pages

- Framework preset: `None`
- Build command: leave blank
- Build output directory: `/`
- Root directory: `/`

All page assets are included in this repository. No build step or environment
variables are required.
